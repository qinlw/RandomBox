# RandomBox · 随机箱子

网易《我的世界》中国版（基岩版）Addon。在游戏里放一个会「自己长东西」的箱子：每个游戏日自动往箱子里塞一件随机物品，满了就不再增长，挖掉重新放置内容也不会丢。

---

## 一、玩法

### 1. 拿到箱子
- 首次进入世界时，系统会自动给玩家发 1 个随机箱子（每人只发一次，进背包并弹出提示）。
- 创造模式物品栏可直接拿：`随机箱子`。
- **没有合成配方**：箱子本体在每日奖池里，生存模式下只能靠箱子每天随机刷新获得（可能需要许愿来加速，见「许愿与献祭」）。
- 箱子是普通方块，可放置、可挖取、可堆叠。手持方块右键箱子只会打开箱子，不会误放置手中方块。

### 2. 自动刷新
- 场上**每一个**箱子都有独立的库存和计时。
- 每过一个**游戏日**（24000 ticks），每个箱子自动 +1 件随机物品。
- 箱子最多 27 格；**满了以后当天不再刷新**，外观会变成「满箱」状态（偏红铜色）。
- 界面开着的时候刷新，物品会实时出现在界面里。

### 3. 打开与外观
- 右键打开箱子，进入容器界面（标题「随机箱子」）。容器共 28 格（7×4 网格）：前 27 格放箱子物品，**右下角第 28 格是独立的献祭格**（网格旁有「献祭」小字标记）。
- 箱子有开盖动画：打开时盖子上翻，关闭时回落。
- 放置时按玩家朝向旋转（四面向），正面是**带锁扣的面板**，其余四面是带「?」的木板面，盖顶是木条纹理。
- 箱子内容与方块绑定，**不是**共用战利品表。
- 手持方块 / 食物右键箱子时不会使用手中物品（服务端取消这次物品使用，并拦下随后 0.6 秒内的方块放置）。

### 4. 挖掉再放置
- 挖掉箱子时，箱内所有物品会跟着这个箱子物品走（记录在物品的 `extraId` 上）。
- 重新放下同一个箱子物品，里面的东西原样还原，不会丢失。
- 拆除瞬间如果方块被其它方式替换，也会走同样的掉落逻辑。

### 5. 许愿与献祭

物品全随机，特别想要某件物品时可以「许愿」。**许愿面板常驻在容器内部右侧**：物品网格整体左移与下方背包左边缘对齐，右侧腾出一条 36px 宽的竖条（图标 → 物品名 → 累计概率 → 概率上限 → 献祭按钮），完全落在容器背景内，不再压到容器边框。许愿物品**不占用任何容器格**：

- **许愿物品**：点竖条顶部的图标按钮，弹出奖池物品选择弹窗（6×4 图标 + 搜索 + 翻页），可以直接选**未拥有**的物品；选中后弹窗关闭，竖条上显示该物品的图标与名称，物品本身不会被消耗。
- **献祭格 = 容器右下角那一格（第 28 格）**：把要献祭的一整组物品点进这一格（原版点背包物品 → 点格子的交互），物品留在这里；点竖条下方的「献祭」按钮才真正消耗掉。点回背包则视为取消。关闭箱子界面时，献祭格里残留的物品会自动退回背包，不会丢失。
- **概率显示**：竖条内两行显示「累计 xx％」与「上限 xx％」。
- **每日判定**：每个游戏日刷新前，先按当前积累概率对许愿物品单独判定一次——命中则当天刷新出许愿物品；未命中则退回原逻辑，从奖池公平随机一件。**每个箱子每天都会各自判定一次**。
- **献祭提概率**：献祭格内的**整组**物品全部计入（想献祭几个就先在背包里拆好组）。
  - 同一种物品第 1 个 +5%，之后每个减半：第 2 个 +2.5%、第 3 个 +1.25%……
  - 例：一次献祭 3 块铁锭 = 5% + 2.5% + 1.25% = **+8.75%**；同种物品无限献祭的极限约 +10%。
  - 增量小于 0.0001% 时不再提升（也不会再累积），避免数值溢出。
- **概率上限**：初始上限 100%，即可以通过献祭堆到必中。**许愿命中一次后**：只清空积累概率，**献祭记录保留**（例如之前献祭过 2 块铁锭、概率堆到 7.5%，命中后概率归零，但铁锭档位已到第 3 档——下次再献祭铁锭只 +1.25%，不会回到 5%）；同时上限 -20%（100 → 80 → … → 0）。上限归 0 后许愿玩法结束，献祭会被拒绝。
- **全世界共享一份**：许愿物品、积累概率、上限都存储在世界数据里，所有随机箱子共用——换箱子不会重置概率，也没法通过换箱子绕过递减的上限。
- **更换许愿物品**：许愿物品只是一个「指针」，改指向**不会**清空已积累的概率，献祭记录与上限也不受影响。也就是说可以先把概率堆到 100%，再任选一件物品作为目标。

## 二、奖池

奖池在运行时从引擎读取，**不用手工维护清单**：

1. 优先取「创造模式物品栏」全部物品；
2. 取不到时退化为「当前加载的全部物品」（会包含其它已加载模组的东西）；
3. 接口都失败时使用内置后备奖池 `loot_pool.py` 的 `POOL`。

生成时会被过滤掉：

- 技术方块 / 占位方块（空气、流水、屏障、结构方块、命令方块等）；
- 刷怪蛋、教育版与化学物品、旧版兼容 ID；
- 「随机箱子·已满」外观方块（仅是显示状态，不能作为物品存在）；
- 已废弃 / 双半砖 / 墙告示牌之类的技术条目。

普通的 `随机箱子` 保留在奖池里——合成配方已移除，这是生存模式获得新箱子的唯一途径。

每件物品数量为 1~3（不超过该物品的最大堆叠数，工具、盔甲、鞘翅、潜影盒等不可堆叠物品固定 1 件）。

## 三、测试指令

只需要测试时可临时打开测试面板：

```
/rp test            切换测试面板开关
/rp test on        打开
/rp test off       关闭
```

`/rb test`、`#rp test`、`!rp test` 写法也兼容。面板里：

- **查看奖池**：复用许愿选择弹窗（6×4 图标 + 搜索 + 翻页），只读状态，点图标不会改许愿物品，点「关闭」返回。
- **测试刷新**：等同于执行一次 `/time add 24000`——把游戏日推进一天，然后对所有箱子跑一遍真实的每日刷新（含许愿判定、满箱跳过、开盖/满箱外观切换），不是单独给某个箱子加物品。箱子满 27 格时会提示「箱子已满，今天不刷新」——每日刷新也是这个规则，所以概率堆到 100％ 时也要留至少一个空位才能收到许愿物品。

## 四、安装

**方式一（推荐）**：把 `RandomBox.mcaddon` 导入网易开发者工具 / 客户端即可。

**方式二（手动）**：

```
MinecraftPE_Netease/games/com.netease/
├── behavior_packs/behavior_pack/     ← behavior_pack 的内容
└── resource_packs/resource_pack/     ← resource_pack 的内容
```

需要注意行为包与资源包必须在同一个「存档」/「游戏」下加载，资源包负责贴图、模型与动画，缺一不可。

## 五、目录结构

```
RandomBox/
├── build.py                     打包脚本：生成 RandomBox.mcaddon / RandomBox.zip
├── behavior_pack/
│   ├── manifest.json
│   ├── netease_blocks/          随机箱子、满箱 的方块定义
│   ├── loot_tables/             空战利品表（内容由脚本维护）
│   ├── texts/                   语言文件（zh_CN.lang）
│   └── randomboxScripts/
│       ├── modMain.py           模组入口
│       ├── randomboxServer.py   服务端：库存、刷新、许愿/献祭、掉落、交互、动画广播
│       ├── randomboxClient.py   客户端：界面事件、许愿面板、实体动画控制
│       └── loot_pool.py         奖池构建与随机抽取
└── resource_pack/
    ├── manifest.json
    ├── blocks.json              方块图标 / 自定义方块实体绑定
    ├── models/entity/           箱子的 3D 模型（箱体 + 可转动的盖子）
    ├── animations/              开盖 / 合盖动画与「模型归位」动画
    ├── animation_controllers/   由 Molang 变量 rbx_open 驱动的状态机
    ├── entity/                  方块实体定义（普通箱 / 满箱）
    ├── render_controllers/
    ├── textures/
    │   ├── blocks/              方块面与物品图标、正面锁扣
    │   └── entity/randombox/    实体图集（48×16：侧面「?」/ 盖顶木条 / 正面锁扣）
    └── ui/                      容器界面（含许愿/献祭面板与物品选择弹窗）
```

## 六、打包

在项目根目录执行：

```bash
python build.py
```

会生成 `RandomBox.mcaddon` 与 `RandomBox.zip`，并做基本的目录结构校验（根目录只允许两个包、检查实体与贴图是否缺失）。

## 七、已知限制

- 箱子库存保存在世界数据里（`rbx_all_chests`），换存档不会带过去；但箱子物品本身带走内容。
- 许愿状态（许愿物品、积累概率、上限、献祭记录）同样保存在 `rbx_all_chests` 中，**全世界共享一份**，多人场景下所有玩家共同推进同一个许愿。
- 容器界面基于网易 UI 容器集合，脚本按 0 起编号读写槽位：0~26 是箱子物品，第 27 号槽位（界面右下角）是献祭格；许愿物品只记录在世界数据里，不占格。
- 「满箱」方块只作为外观状态自动切换，不注册到创造菜单，手动放置请用普通的 `随机箱子`。
- 刷新以游戏内日期为基准，睡觉跳过夜晚也会正常触发。
